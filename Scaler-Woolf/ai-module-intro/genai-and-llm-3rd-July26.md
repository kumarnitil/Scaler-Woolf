# Creating Running notes
## Definitions
- **AI - Artificial Intelligence** - Any software system which would perform tasks we would otherwise call as intelligent.
Example - SPAM Filter in email, face unlocking in phone
- **LLM-Deep Learning - Machine Learning (Narrow AI and General AI) - Artificial Intelligence**
- **Generative AI** - AI that creates new contents. While traditional AI classifies, predicts, or recommends, Generative AI writes, draws, composes, and codes.
- **GenAI by modality (what it can create):** - Modality simply means "the type of content." Text, image, audio, video — each is a different modality. Think of modalities as different languages that AI can speak.
- **Large Language Model (LLM):** - An AI system trained on massive amounts of text to predict the **next word (or "token")** in a sequence. You give it text, it continues the text.
- **Token** - A token is a small chunk of text that a model reads and predicts step by step. Tokens can be whole words, parts of words, punctuation, or even spaces depending on how the text is split.
- **Multi-modal** - means the model can work with more than one type of input or output
- **AI Agent** - A system that doesn't just answer questions — it completes tasks. It can use tools, remember past interactions, and decide what to do next on its own.
